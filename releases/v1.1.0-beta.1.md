# Kolibri Print v1.1.0-beta.1

**Canal:** Beta / pré-release  
**Data:** 2026-10-02  
**Instalador:** `KolibriPrint_Setup_v1.1.0-beta.1.exe`

## Destaques

- Autenticação individual por cliente com ECDSA P-256.
- Pareamento por janela temporária e código de uso único.
- Revogação real de clientes, inclusive para a impressão universal do Windows.
- Kolibri Print Forwarder local em loopback.
- Transporte de impressão autenticado pelo Agent.
- Migração de filas Kolibri existentes para o novo fluxo.
- Criação automática de porta e fila no Windows 11.
- Compatibilidade validada em uso real com Epson LX-350 ESC/P.
- Uso normal por Word, navegador, PDF e outros aplicativos do Windows.

## Status

Esta é uma **versão beta**. Não é a versão final v1.1.0.

As Fases 3, 4 e 5 do roadmap continuam em desenvolvimento antes do release estável.
