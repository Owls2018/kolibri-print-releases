# Changelog

Todas as versões públicas do Kolibri Print serão registradas neste arquivo.

O formato segue versionamento semântico (`MAJOR.MINOR.PATCH`) e cada versão publicada deve ter uma Release correspondente no GitHub com instalador, notas e SHA-256.

## Beta

### v1.1.0-beta.1 — 2026-10-02

Primeira beta pública preparada para distribuição controlada. Inclui autenticação individual, revogação real, Forwarder local, transporte autenticado e criação automática de filas no Windows.

SHA-256 do instalador: `20adb656098d3e08c613be5ed999209928de7c48a063d7c13f6b2351260d7faa`.
